Обновлено 22 ноября 2026 года, Москва.

## Где искать проект

- Локальный репозиторий находится в ~/Documents/ChatGPT/maya site. Удалённый репозиторий — https://github.com/b1moteen/maya-site.
- Рабочая ветка для запуска, продвижения и дальнейших правок — `maya-client-launch` ([ветка на GitHub](https://github.com/b1moteen/maya-site/tree/maya-client-launch)). Для нового чата начните с `git fetch origin`, затем переключитесь на `maya-client-launch`. В свежем клоне используйте `git switch --track origin/maya-client-launch`.
- [План продвижения и измерения результатов](PROMOTION_HANDOFF.md) описывает, что можно подготовить, какие проверки нужны перед анонсами и какие решения согласует организатор.
- [Черновики анонсов и отчёта](CAMPAIGN_DRAFTS.md) содержат готовые UTM-ссылки и поисковые гипотезы; публикация зависит от подтверждения мест и согласования.
- Актуальный публичный сайт — https://www.maya-velikolepnaya.ru/. Прямая ссылка для компаний — https://www.maya-velikolepnaya.ru/corporate/. GitHub Pages https://b1moteen.github.io/maya-site/ показывает прежнюю версию из main.
- Превью на Mac — http://127.0.0.1:8765/ и http://127.0.0.1:8765/corporate/. Для запуска, сборки и отката используйте [README.md](README.md).

## Что согласовано и реализовано

- Статический сайт без сервера и фреймворка. Театральная палитра, типографика и фотографии спектакля.
- Главная для зрителей ведёт в IceTickets. Согласованная афиша включает 21 и 28 ноября, 5 и 12 декабря 2026 года. Начавшиеся сеансы скрываются по времени Москвы. Минимальная цена появится на сайте после подтверждения для ближайшего показа.
- Страница /corporate/ открывается в той же вкладке. Групповое посещение и закрытый показ представлены равными блоками. Основной контакт — Telegram, дополнительные — телефон и почта. У двух форматов разные черновики сообщения. Контакты и тексты редактируются в corporate/index.html.
- Проверено в Chromium и WebKit, включая узкий экран, тёмную тему, основные ссылки без JavaScript и переходы из подпапки. Сборка создаёт данные для SEO и карточки ссылки отдельно для обеих страниц. Код Метрики готов, события проверены с тестовым ID и заблокированным сетевым запросом.

## Приёмка и публикация

- Денис подтвердил мобильную проверку корпоративной страницы 21 ноября 2026 года.
- Публичный сайт размещён на Selectel S3 + CDN. Релиз `1525d9d` собран для домена с `www` со счётчиком Яндекс Метрики `114450168`. Все 31 файла сборки совпали с содержимым бакета. Прежнюю публичную сборку сохранили локально в архиве для отката.
- 22 ноября после выборочной очистки CDN главная и `/corporate/` вернули HTTP 200 по HTTPS, их HTML совпал со сборкой со счётчиком. `robots.txt`, `sitemap.xml` и `analytics.js` также прошли проверку. На момент проверки панель Selectel ещё показывала `PROCESSING`. Адрес без `www` ранее вернул HTTP 403.
- В счётчике есть цели `ticket_click`, `corporate_telegram`, `corporate_phone` и `corporate_email`. Все четыре тестовых клика подтвердил браузерный отладчик Метрики на публичном домене. Для тестового трафика использован `utm_source=deploy_qa`. Достижения в отчёте по UTM пока не сверены.
- Афиша сверена с IceTickets. По согласованию добавлен показ 12 декабря в 19:00 с прямой ссылкой на выбор билетов.
- 22 ноября повторно проверены обе страницы с `www`, счётчик в HTML, карта сайта и билетные URL с ответом HTTP 200. Адрес HTTP с `www` не перенаправляется на HTTPS; адрес без `www` вернул 403. CDN Selectel остаётся в `PROCESSING`, настройки перенаправления недоступны. 404 для отсутствующей страницы работает. Доступность конкретных мест и цены ответ HTTP не подтверждает.
- 22 ноября владелец подтвердил права на сайт в Яндекс Вебмастере через файл в корне сайта. Карта сайта доступна по адресу `https://www.maya-velikolepnaya.ru/sitemap.xml` и указана в `robots.txt`, но вручную ещё не отправлена: Вебмастер сообщает, что инструмент Sitemap временно работает только для чтения. Повторить отправку после восстановления инструмента. Файл подтверждения в корне сайта необходимо сохранять при обновлениях. Google Search Console и Вордстат не проверены.
- 22 ноября Денис сообщил, что показы 28 ноября, 5 и 12 декабря, наличие мест, цены и рекламный тест до 6 000 ₽ с НДС подтверждены. Конкретные значения цен не названы. Резерв на 12 декабря требует отдельного решения. Перед фактическим запуском рекламы повторно проверить наличие мест и измерение целей.
- Текущий Яндекс-аккаунт открыл страницу первичной регистрации Директа: Россия и рубли, регистрация сопровождается принятием оферты и соглашения об обработке данных. Регистрация владельцем и создание кампании ещё не завершены. CDN Selectel по-прежнему показывал `PROCESSING`, настройки редиректа были недоступны.
- 22 ноября повторно проверен Директ: кабинет зарегистрирован, баланс отображается 0 ₽, пользователь выбрал обычный интерфейс. Настроенный в плане поисковой тест требует отдельного выбора площадки, доступного в Единой перфоманс-кампании; кампанию ещё не создали. Вордстат проверен для Москвы, данные и периоды сохранены в `CAMPAIGN_DRAFTS.md`.
- 22 ноября CDN стал `ACTIVE`, включено автоматическое перенаправление HTTP на HTTPS, Selectel применяет изменение (`PROCESSING`). Повторно проверить фактический редирект с путём и UTM после применения. Google Search Console запросил вход в аккаунт; Sitemap в Яндекс Вебмастере пока доступен только для чтения.
- 22 ноября пользователь вошёл в Google. URL-префикс `https://www.maya-velikolepnaya.ru/` подтверждён в Google Search Console через файл `google17fc277820a00959.html` в корне. Карту сайта отправили: сразу после отправки Google показывал `Couldn't fetch`, хотя проверка HTTP с user-agent Googlebot вернула 200; повторно проверить обработку. Главная имела статус `Discovered - currently not indexed`, корпоративная страница была неизвестна Google. Для обеих отправлены запросы на индексирование, Google подтвердил постановку в очередь. Это не подтверждает их появление в поиске. Сохранять оба файла подтверждения Google и Яндекса при обновлениях.
- При проверке 22 ноября в отчёте Метрики по цели `ticket_click` раскрыта группировка UTM Source: источник `deploy_qa`, одно достижение и один целевой визит. Это тестовое достижение, а не продажа. Проверены HEAD-запросами 22 внутренние ссылки и ресурса с обеих страниц: все вернули 200. Selectel продолжает применение HTTP→HTTPS (`PROCESSING`), на момент проверки HTTP ещё отдавал 200 без редиректа. Sitemap в Google всё ещё `Couldn't fetch`.

## Что остаётся после публикации

3. **Обновления.** Собирать следующий релиз через tools/build_release.py для https://www.maya-velikolepnaya.ru и соблюдать порядок загрузки и проверки из README.md. Реквизиты доступа хранить отдельно.
