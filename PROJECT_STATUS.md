# Майя Великолепная — статус проекта для других чатов

Обновлено 21 ноября 2026 года, Москва.

## Где искать проект

- Локальный репозиторий находится в ~/Documents/ChatGPT/maya site. Удалённый репозиторий — https://github.com/b1moteen/maya-site.
- Проверенная версия для следующего релиза находится в локальной ветке maya-client-launch. Точный коммит можно получить командой git rev-parse maya-client-launch в репозитории.
- Публичная версия GitHub Pages работает из ветки main по адресу https://b1moteen.github.io/maya-site/. Доработки готовы локально.
- Превью на Mac — http://127.0.0.1:8765/ и http://127.0.0.1:8765/corporate/. Для запуска, сборки и отката используйте [README.md](README.md).

## Что согласовано и реализовано

- Статический сайт без сервера и фреймворка. Театральная палитра, типографика и фотографии спектакля.
- Главная для зрителей ведёт в IceTickets. Согласованная афиша включает 21 и 28 ноября и 5 декабря 2026 года. Начавшиеся сеансы скрываются по времени Москвы. Минимальная цена появится на сайте после подтверждения для ближайшего показа.
- Страница /corporate/ открывается в той же вкладке. Групповое посещение и закрытый показ представлены равными блоками. Основной контакт — Telegram, дополнительные — телефон и почта. У двух форматов разные черновики сообщения. Контакты и тексты редактируются в corporate/index.html.
- Проверено в Chromium и WebKit, включая узкий экран, тёмную тему, основные ссылки без JavaScript и переходы из подпапки. Сборка создаёт данные для SEO и карточки ссылки отдельно для обеих страниц. Код Метрики готов, события проверены с тестовым ID и заблокированным сетевым запросом.

## Что остаётся перед рассылкой

1. **Хостинг и домен.** Это отдельный чат. Бюджет до 1 000 ₽ в месяц, новый домен оплачивается отдельно. Кандидаты — Selectel S3 + CDN и Yandex Object Storage + Cloud CDN. Сверить итоговую цену, доступ из российских сетей, HTTPS, заголовки безопасности и условия защиты. Исходник для развёртывания — проверенный Git-релиз.
2. **Выпуск.** Запустить tools/build_release.py с окончательным HTTPS-адресом и загрузить содержимое полученной папки. Проверить, что прямой запрос /corporate/ возвращает корпоративную страницу и оба адреса входят в sitemap.xml. Сверить афишу и контакты непосредственно перед рассылкой.
3. **Поиск и метрики.** После запуска проверить карточки обеих ссылок, добавить сайт в Яндекс Вебмастер и Google Search Console, проверить события с реальным ID счётчика. Реквизиты доступа хранятся отдельно.

После публикации обновите этот файл, указав публичный адрес, коммит релиза и результаты проверки.
