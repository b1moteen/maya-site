# Майя Великолепная — сайт спектакля

Статичный сайт без сборки: `index.html` + папка `assets/` (фото и видео).

## Как выложить на GitHub Pages (бесплатно)
1. На github.com создайте репозиторий, например `maya-site` (Public).
2. **Add file → Upload files**: перетащите `index.html`, `.nojekyll` и папку `assets`, нажмите Commit.
3. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)`, Save.
4. Через 1–2 минуты сайт откроется по адресу `https://b1moteen.github.io/maya-site/`.

## Свой домен
Купите домен, в DNS добавьте CNAME на `b1moteen.github.io`, затем в **Settings → Pages → Custom domain** впишите домен и включите HTTPS.

## Что редактируется в index.html
- Даты и статусы (`''` / `'low'` — мало мест): массив `days` в блоке `<script>` внизу. «Аншлага» и фейковых дат нет.
- Цены: только диапазон «От 2 500 ₽ до 5 000 ₽» в блоке «Билеты» (счётчиков и массива `T` нет).
- Ссылка на покупку (icetickets.ru) повторяется во всех `a[data-buy]` (шапка, кнопки, ряды дат в скрипте, нижняя панель) и в подвале у QR — меняется одним поиском/заменой по `icetickets.ru/meropriyatie/...`. QR: `assets/qr-tickets.png` (пересоздать под новую ссылку).
- Отзывы: блок `id="rev"` — **замените на настоящие**.
- Фото и видео: файлы в `assets/`.

- [ ] Страницы: публичная оферта, политика конфиденциальности, условия возврата — составить с юристом; добавить ссылки в подвал.

- [ ] Яндекс Метрика и Яндекс Вебмастер; для превью в соцсетях добавить `og:image` с абсолютной ссылкой на фото.
