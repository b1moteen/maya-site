# «Майя Великолепная»

Статический сайт: `index.html`, `site.js` и `assets/`. Исходная версия закрыта от поисковой индексации; для публикации используйте отдельную сборку.

## Проверка и обновление

Запустите в папке проекта `python3 -m http.server 8000` и откройте <http://localhost:8000/>. Проверьте сайт на телефоне и компьютере, ссылки, фото и видео.

- Афиша находится в `index.html`: для каждого показа обновите строку даты, `datetime` с московским смещением `+03:00`, `data-show-date`, подпись и адрес кнопки билетов. Проверьте соответствие дат реальным событиям у билетного оператора. Ссылку «Смотреть афишу» оставьте ведущей на общую афишу: это резервный вариант, если отдельных показов нет.
- Блок «Для компаний» (`id="corporate"`): проверьте текст и контакты Telegram, телефона и почты с организатором.
- Цена по умолчанию скрыта. Указывайте минимальную цену только после подтверждения для ближайшего показа через `--from-price`; без неё посетитель проверяет цену у билетного оператора.
- QR-код `assets/qr-tickets.png` ведёт на общую афишу. При смене адреса пересоздайте QR и проверьте его камерой телефона; обновите и ссылку рядом с ним.
- До запуска согласуйте контакты, даты и цены, права на фото и видео, реквизиты и необходимые правовые документы. Проверьте все утверждения на странице с организатором.

## Аналитика

Для включения Яндекс Метрики создайте счётчик и передайте его числовой ID при сборке. В интерфейсе Метрики настройте JavaScript-события с идентификаторами `ticket_click`, `corporate_telegram`, `corporate_phone`, `corporate_email`. После публикации проверьте события через инструменты Метрики и тестовые нажатия. Без ID счётчик не подключается.

Примеры ссылок для разных каналов (замените `example.com` своим доменом):

- Telegram: `https://example.com/?utm_source=telegram&utm_medium=social&utm_campaign=launch`
- VK: `https://example.com/?utm_source=vk&utm_medium=social&utm_campaign=launch`
- Партнёр: `https://example.com/?utm_source=partner&utm_medium=referral&utm_campaign=launch`

## Поиск и предпросмотр ссылки

После подключения постоянного домена проверьте карточку ссылки в мессенджере, подтвердите право на сайт в Яндекс Вебмастере и Google Search Console и отправьте карту сайта. Для сверки поискового спроса в Вордстате начните с Москвы и запросов «Майя Великолепная», «спектакль Майя Великолепная билеты», «балетный спектакль в Москве», «закрытый показ спектакля для компании». Сопоставьте частотность с содержанием и точным намерением запроса.

## Сборка и публикация

1. До покупки и публикации согласуйте сайт, домен, реквизиты, аналитику и бюджет с владельцем. Для нового домена настройте DNS и HTTPS. Первый вариант — Selectel S3 + CDN за 550 ₽/мес. за CDN с пакетом 800 ГБ, плюс S3. Резервный — Yandex Object Storage + Cloud CDN за 150 ₽/мес. за CDN с пакетом 150 ГБ, плюс хранилище. Уточните связанные расходы, доступность из РФ и состав защиты перед оплатой. [Selectel](https://docs.selectel.ru/cdn/about/about-cdn/) · [Yandex Cloud](https://yandex.cloud/ru/docs/cdn/pricing)
2. Из корня проекта соберите релиз в **новую** папку вне проекта, подставив свой HTTPS origin без завершающего слеша и пути:

   ```sh
   python3 tools/build_release.py https://example.com /tmp/maya-release --metrika-id 12345678 --from-price 2500
   ```

   Оба параметра необязательны. Если папка уже существует, выберите новое имя. Скрипт добавляет адреса для поисковиков и предпросмотра, `robots.txt`, `sitemap.xml` и при наличии ID разрешения CSP для счётчика. Он не изменяет исходники и ничего не публикует.
3. Проверьте сборку локально: `python3 -m http.server 8000 --directory /tmp/maya-release`. Откройте страницу и проверьте дату, кнопки, цену, QR, контакты и аналитику. Убедитесь, что `robots.txt`, `sitemap.xml`, canonical и картинка предпросмотра используют правильный домен.
4. Сохраните копию предыдущего релиза отдельно от хостинга. Загрузите **содержимое** папки релиза, назначьте index.html главной страницей, привяжите домен и включите HTTPS. Доступ на запись выдайте ответственному аккаунту только для нужного бакета. Настройте заголовки X-Content-Type-Options, Referrer-Policy и CSP с frame-ancestors 'none' на CDN.
5. Очистите кэш CDN. Проверьте главную страницу, выдачу видео и карты сайта, предпросмотр ссылки, цели Метрики и оба клиентских маршрута с домашней и мобильной сети из РФ. При наличии доступа настройте 301 со старого домена на новый.
6. При проблеме восстановите сохранённые файлы предыдущего релиза, очистите кэш CDN и проверьте главную страницу, покупки и контакты. Сохраните копию сборки и настройки DNS для повторной проверки.
